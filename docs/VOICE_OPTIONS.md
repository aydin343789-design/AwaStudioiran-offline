# مدل صدا، ریتم و گزینه‌های آینده

## قابلیت فعلی اپ

اپ محلی از `fa_IR-amir-medium` استفاده می‌کند. صدای تولیدشده را می‌توان شنید و سپس به MP3 دانلود یا در پوشهٔ موسیقی ذخیره کرد. پنج preset رابط به سرعت بازنمونه‌گیری قبل از MP3 وصل شده‌اند:

| حالت | سرعت |
|---|---:|
| عادی | 1.00× |
| رسمی | 0.94× |
| خبری | 1.07× |
| شاد | 1.08× |
| صمیمی | 0.96× |

این تغییرات فقط ریتم و pitch را کمی جابه‌جا می‌کنند؛ مدل Piper برای هر preset بازیگری، احساس، لهجه یا طنین تازه‌ای تولید نمی‌کند. بنابراین کیفیت و جنس پایهٔ صدا همان صدای Amir می‌ماند.

## زن و کودک

بالابردن pitch صدای مرد، آن را به صدای طبیعی زن یا کودک تبدیل نمی‌کند. تغییر pitch ساده می‌تواند سرعت را هم عوض کند و طنین/فرمنت‌های گلو را حفظ نمی‌کند؛ تغییر شدید معمولاً صدای مصنوعی یا «چیپ‌مانک» می‌دهد. برای خروجی‌ای که واقعاً طبیعی باشد، به مدل فارسی جداگانه و مجاز برای هر شخصیت، دادهٔ باکیفیت و ارزیابی شنیداری نیاز است. تا آن زمان گزینه‌های زن و کودک در رابط غیرفعال هستند و خروجی اشتباه به کاربر نسبت داده نمی‌شود.

یک مدل فارسی VITS زنانه در Hugging Face پیدا شد، اما کارت آن می‌گوید مدل تک‌گوینده است، برای اجرا نمونهٔ Coqui TTS با فایل checkpoint (`.pth`) و config ارائه می‌کند و دادهٔ آموزشی را «persian-tts-dataset-male» معرفی می‌کند. در کارت بازیابی‌شده مجوز روشنی برای بازتوزیع دیده نشد؛ بنابراین آن را وارد APK نکردیم. مدل‌های Piper موجود نیز مستقیماً از طریق API فعلی Piper Web قابل انتخاب‌اند، اما داشتن چند مدل مردانه به‌معنی وجود صدای زنانه یا کودک نیست.

## منابع بررسی‌شده

- فهرست رسمی مدل‌های فارسی Piper: https://huggingface.co/rhasspy/piper-voices/tree/main/fa/fa_IR
- کارت `fa_IR-gyro-medium`: https://huggingface.co/rhasspy/piper-voices/blob/main/fa/fa_IR/gyro/medium/MODEL_CARD — یک گوینده، کیفیت medium، ۲۲٫۰۵ کیلوهرتز و fine-tune شده از دیتاست Persian TTS Male؛ کارت برای مجوز داده به منبع سازنده ارجاع می‌دهد.
- کارت مدل فارسی VITS زنانه: https://huggingface.co/Kamtera/persian-tts-female-vits — نمونهٔ اجرا بر پایهٔ Coqui TTS و وزن `.pth`؛ ادعای «female voice» همراه با اشاره به دیتاست «male» نیازمند ارزیابی و روشن‌شدن مجوز است.
- MP3 encoder بسته‌شده در برنامه: https://www.npmjs.com/package/@breezystack/lamejs — نسخهٔ 1.2.7، مجوز LGPL-3.0. جزئیات در `THIRD_PARTY_NOTICES.md` آمده است.

## مسیر پیشنهادی

برای فعال‌کردن شخصیت زن یا کودک، ابتدا مدل فارسی با مجوز و حق استفادهٔ روشن انتخاب شود، چند جملهٔ معیار روی گوشی‌های ضعیف تست شود، اندازهٔ مدل و سرعت محاسبه سنجیده شود و فقط بعد از تأیید کیفیت در UI فعال گردد. استفاده از voice conversion یا pitch-shift شدید به‌عنوان جایگزین مدل واقعی پیشنهاد نمی‌شود.
