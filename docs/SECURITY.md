# امنیت API — آوای ایران آزاد

- API Key در APK وجود ندارد.
- API Key فقط در Secret سمت Gateway نگهداری می‌شود.
- کلاینت فقط URL Gateway را می‌داند.
- Gateway مدل‌ها، طول متن و محدوده تنظیمات صوتی را محدود می‌کند.
- برای انتشار عمومی گسترده، احراز هویت کاربران و سهمیه‌بندی per-user/rate limit باید اضافه شود.
- API Key را هرگز در GitHub commit نکنید.
