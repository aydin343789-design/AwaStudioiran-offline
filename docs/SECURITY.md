# امنیت

- در APK هیچ API token قرار نمی‌گیرد. `PIPER_API_TOKEN` فقط بین Cloudflare Worker و API خودمیزبان است.
- Worker و API باید از HTTPS استفاده کنند. برای سرویس Piper یک token تصادفی و بلند انتخاب کنید.
- API عمومی نباید بدون احراز هویت کاربر و rate limit منتشر شود؛ Worker فعلی محدودیت طول متن دارد، اما سهمیهٔ per-user یا ضدسوءاستفادهٔ پایدار ندارد.
- مدل گفتار و متن ورودی می‌توانند محتوای خصوصی کاربر را شامل شوند. حالت محلی متن را برای تولید صدا به API بیرونی نمی‌فرستد؛ در حالت آنلاین متن به میزبان Piper شما ارسال می‌شود.
- وابستگی‌های متن‌باز و اعلان‌های مجوز در `THIRD_PARTY_NOTICES.md` آمده‌اند.
