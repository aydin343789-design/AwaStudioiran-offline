# سرویس آنلاین متن‌باز Piper برای آوای ایران آزاد

این API مدل فارسی Piper را روی سرور خودتان اجرا می‌کند؛ برای هر کاراکتر هزینهٔ سرویس‌دهندهٔ TTS ندارد. موتور Piper به‌صورت wheel آمادهٔ Python نصب می‌شود و به کامپایل ONNX روی رایانهٔ توسعه‌دهنده نیاز نیست. سرور در شروع کار مدل حدود ۶۴ مگابایتی را دریافت و در `/data/piper` نگه می‌دارد.

## اجرا با Docker

```bash
cd server/piper-api
docker build -t avaye-piper-api .
docker run --rm -p 7860:7860 \
  -e PIPER_API_TOKEN='یک-توکن-تصادفی-بلند' \
  -v piper-model:/data/piper \
  avaye-piper-api
```

در نخستین start، سرور به اینترنت برای دریافت مدل نیاز دارد. پس از آن volume باعث می‌شود مدل محلی باقی بماند. برای بررسی آمادگی:

```bash
curl http://localhost:7860/health
```

نمونهٔ درخواستِ احراز هویت‌شده:

```bash
curl -X POST http://localhost:7860/v1/tts \
  -H 'Authorization: Bearer یک-توکن-تصادفی-بلند' \
  -H 'Content-Type: application/json' \
  -d '{"text":"سلام، این یک آزمایش است.","voiceId":"fa_IR-amir-medium","speed":1.0}' \
  --output sample.wav
```

## اتصال به برنامه از طریق Cloudflare Worker

در تنظیمات Worker این دو مقدار را تعریف کنید:

- `PIPER_API_URL`: نشانی HTTPS سرویس Docker که از اینترنت قابل‌دسترسی است، بدون `/` پایانی.
- `PIPER_API_TOKEN`: دقیقاً همان توکنِ تنظیم‌شده در سرور؛ این مقدار فقط بین Worker و API است و نباید داخل APK گذاشته شود.

سپس `server/worker.js` را در Cloudflare Worker منتشر کنید و آدرس Worker را داخل تنظیمات اپ وارد کنید. مسیر online برنامه از آن پس به API متن‌باز Piper می‌رود، نه ElevenLabs.

## نکتهٔ هزینه/دسترس‌پذیری

کد و مدلِ تعیین‌شده هزینهٔ مصرفی به‌ازای متن ندارند؛ اما یک API آنلاین باید جایی اجرا شود. می‌توانید آن را روی رایانهٔ خودتان اجرا کنید (رایانه باید روشن و قابل‌دسترسی باشد) یا روی سرور میزبانی کنید. هیچ میزبانی عمومیِ دائمیِ رایگان و تضمین‌شده‌ای را نمی‌توان فرض کرد؛ طرح‌های رایگان ممکن است بخوابند، کند باشند، محدودیت داشته باشند یا تغییر کنند. برای استفادهٔ عمومی و پایدار، محدودسازی درخواست/کاربر و منابع میزبانی لازم است.

## مدل و محدودیت‌ها

مدل پیش‌فرض `fa_IR-amir-medium` یک صدای فارسی تک‌گوینده با کیفیت «medium» و نرخ ۲۲٫۰۵ کیلوهرتز است. حالت online ویژگی‌های سبک ElevenLabs مانند clone، کارگردانی احساسی، یا چندصدایی ندارد. مدل از مخزن [Piper voices](https://huggingface.co/rhasspy/piper-voices/tree/main/fa/fa_IR/amir/medium) بارگیری می‌شود. مجوزهای runtime و مدل مستقل‌اند؛ پیش از بازتوزیع تجاری، اعلان‌های `THIRD_PARTY_NOTICES.md` و کارت مدل را بررسی کنید.
