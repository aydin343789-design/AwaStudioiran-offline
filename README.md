# آوای ایران آزاد

اپلیکیشن Android برای تبدیل متن فارسی به گفتار با مدل متن‌باز Piper. رابط از نو با تم سرمه‌ای/طلایی طراحی شده و خروجی MP3 را روی گوشی می‌سازد.

## رابط و خروجی

- ورود متن تا ۳۰۰۰ نویسه، نمایش درصد تولید، پیش‌نمایش صوتی، تاریخچه و ذخیره در پوشهٔ Downloads یا Music.
- مدل Piper و آماده‌سازی صوت در Web Worker انجام می‌شود تا رابط هنگام تولید پاسخ‌گو بماند.
- سرعت بیان و زیر و بمی صدا جداگانه کنترل می‌شوند؛ presetهای عادی، رسمی، خبری، شاد و صمیمی از صفحه یا تنظیمات منو قابل انتخاب‌اند. این presetها کنترل احساس واقعی یا بازیگری صدا نیستند.
- صداهای آفلاین: مردانهٔ `fa_IR-amir-medium` و زنانهٔ `fa_IR-mana-medium`. کارت «کودک‌نما» افکت آزمایشی pitch روی مدل زنانه است، نه یک مدل یا صدای واقعی کودک.

## دو حالت تولید

- **محلی/آفلاین:** Piper در WebAssembly داخل WebView اجرا می‌شود؛ سرور Python یا Termux لازم نیست. هنگام اولین اجرای آنلاین، اپ فایل‌های runtime و هر دو مدل ناقص را در پس‌زمینه می‌گیرد و در OPFS/IndexedDB گوشی نگه می‌دارد. مجموع دو مدل حدود ۱۲۸ مگابایت است. پس از تکمیل دریافت، تولید با همان مدل‌ها بدون اینترنت انجام می‌شود؛ فایل‌های cache‌شده دوباره دانلود نمی‌شوند.
- **آنلاین:** برنامه به Cloudflare Worker و سپس API خودمیزبان Piper وصل می‌شود. برای API آنلاین باید خودتان یک میزبان در دسترس داشته باشید؛ رایگان‌بودن دائمی میزبانی عمومی تضمین‌شده نیست. جزئیات در `server/piper-api/README.md` آمده است.

## ساخت APK

نیازمندی‌ها: Node.js 22، Java و Android SDK.

```bash
npm ci
npm run build
npx cap sync android
cd android
./gradlew assembleDebug
```

یا GitHub Actions را اجرا کنید؛ workflow خروجی وب را با Vite bundle می‌کند و سپس APK می‌سازد. وزن مدل ONNX و runtime WASM داخل APK قرار ندارند و هنگام آماده‌سازی روی گوشی دانلود می‌شوند.

## صدا و محدودیت‌ها

موتور Piper، صدای Amir و صدای زنانهٔ Mana روی دستگاه اجرا می‌شوند. SoundTouch برای تغییر مستقل سرعت و زیر‌وبمی، و lamejs برای ساخت MP3 استفاده شده است. تغییر لحن‌ها از راه تنظیمات سرعت، pitch و مکث انجام می‌شود؛ مدل پایه همچنان می‌تواند در نام‌های خاص یا واژه‌های ناآشنا تلفظ نادقیق داشته باشد و هیچ تضمین بی‌خطایی وجود ندارد. جزئیات در [`docs/VOICE_OPTIONS.md`](docs/VOICE_OPTIONS.md) و مجوزها در [`THIRD_PARTY_NOTICES.md`](THIRD_PARTY_NOTICES.md) است.

## نکتهٔ سازگاری

برای حالت محلی، WebView گوشی باید از WebAssembly، OPFS و AudioWorklet پشتیبانی کند؛ در صورت خطای آماده‌سازی یا افکت صوتی، Android System WebView یا Chrome را به‌روز کنید. برای دریافت نخستین فایل‌های runtime و مدل‌ها اتصال اینترنت لازم است.
