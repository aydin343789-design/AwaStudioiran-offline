# آوای ایران آزاد

اپلیکیشن Android برای تبدیل متن فارسی به گفتار با مدل متن‌باز Piper. رابط از نو با تم سرمه‌ای/طلایی طراحی شده و خروجی MP3 را محلی می‌سازد.

## رابط و خروجی

- ورود متن تا ۳۰۰۰ نویسه، پیش‌نمایش صوتی، تاریخچه و ذخیره در پوشهٔ Downloads یا Music.
- ریتم‌های عادی، رسمی، خبری، شاد و صمیمی از صفحه یا تنظیمات منوی سه‌خطی قابل انتخاب‌اند؛ slider سرعت/ضرب‌آهنگ هم در همان تنظیمات قرار دارد. این‌ها کنترل احساس یا بازیگری صدا نیستند.
- صداهای آفلاین: مردانهٔ `fa_IR-amir-medium` و زنانهٔ `fa_IR-mana-medium`. صدای زن در اولین انتخاب جداگانه دانلود می‌شود؛ کارت کودک تا یافتن مدل فارسی واقعی و مجاز غیرفعال است.

## دو حالت تولید

- **محلی/آفلاین:** Piper در WebAssembly داخل WebView اجرا می‌شود؛ سرور Python یا Termux لازم نیست. runtime مرورگری و مدل انتخاب‌شده از اینترنت دریافت و در حافظهٔ محلی گوشی ذخیره می‌شوند. دانلود هر مدل حدود ۶۴ مگابایت است؛ اگر هر دو صدا را انتخاب کنید هر دو جداگانه cache می‌شوند. بعد از کامل‌شدن دانلود، تولید با همان مدل بدون اینترنت انجام می‌شود. وزن مدل داخل APK قرار نمی‌گیرد و runtime نیز هنگام build APK کامپایل native نمی‌شود.
- **آنلاین:** برنامه به Cloudflare Worker و سپس API خودمیزبان Piper وصل می‌شود. مدل و runtime آزاد و بدون هزینهٔ هر کاراکتر هستند؛ برای API آنلاین باید خودتان یک میزبان در دسترس داشته باشید. رایگان‌بودن دائمیِ میزبانی عمومی تضمین‌شده نیست. جزئیات در `server/piper-api/README.md` آمده است.

## ساخت APK

نیازمندی‌ها: Node.js 22، Java و Android SDK.

```bash
npm ci
npm run build
npx cap sync android
cd android
./gradlew assembleDebug
```

یا GitHub Actions را اجرا کنید؛ workflow خروجی web را با Vite bundle می‌کند و سپس APK را می‌سازد. مدل ۶۴ مگابایتی و runtime حدود ۲۹ مگابایتی در مخزن نگهداری نمی‌شوند و هنگام راه‌اندازی در cache گوشی دانلود می‌شوند.

## صدای فارسی و مجوز

صدای پیش‌فرض یک گویندهٔ فارسی ایران، کیفیت medium و نرخ ۲۲٫۰۵ کیلوهرتز است. موتور Python Piper در سرویس آنلاین و کتابخانهٔ Piper WebAssembly در برنامهٔ محلی استفاده می‌شوند. presetهای لحن با تغییر سرعت و در نتیجه pitch کمی متفاوت می‌شوند؛ برای صدای طبیعی زنانه/کودک یا احساس واقعی باید مدل‌های جداگانه و مناسب اضافه شوند. جزئیات بررسی در [`docs/VOICE_OPTIONS.md`](docs/VOICE_OPTIONS.md) و اعلان مجوزها در [`THIRD_PARTY_NOTICES.md`](THIRD_PARTY_NOTICES.md) است.

## نکتهٔ سازگاری

برای حالت محلی، WebView گوشی باید از WebAssembly SIMD و فضای ذخیره‌سازی OPFS پشتیبانی کند؛ در صورت خطای آماده‌سازی، Android System WebView یا Chrome را به‌روز کنید. نخستین بار برای دریافت فایل‌های runtime و مدل اتصال اینترنت لازم است.
