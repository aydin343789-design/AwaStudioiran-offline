# آوای ایران آزاد

اپلیکیشن Android برای تبدیل متن فارسی به گفتار با مدل متن‌باز Piper. نسخهٔ جدید از موتور گفتار گوشی یا API تجاری ElevenLabs استفاده نمی‌کند.

## دو حالت تولید

- **محلی/آفلاین:** Piper در WebAssembly داخل WebView اجرا می‌شود. در اولین آماده‌سازی، runtime مرورگری و صدای `fa_IR-amir-medium` از اینترنت دریافت و در حافظهٔ محلی گوشی ذخیره می‌شوند؛ مجموع دانلود اولیه حدود ۹۰ مگابایت است. پس از کامل‌شدن آن، تولید صدا بدون اینترنت انجام می‌شود. فایل مدل داخل APK قرار نمی‌گیرد و runtime نیز در build APK کامپایل native نمی‌شود.
- **آنلاین:** برنامه به Cloudflare Worker و سپس API خودمیزبان Piper وصل می‌شود. مدل و runtime آزاد و بدون هزینهٔ هر کاراکتر هستند؛ برای API آنلاین باید خودتان یک میزبان در دسترس داشته باشید. رایگان‌بودن دائمیِ میزبانی عمومی تضمین‌شده نیست. جزئیات در `server/piper-api/README.md` آمده است.

## ساخت APK

نیازمندی‌ها: Node.js 22، Java و Android SDK.

```bash
npm ci
npm run build
npx cap sync android
cd android
./gradlew assembleDebug
```

یا GitHub Actions را اجرا کنید؛ workflow خروجی web را با Vite bundle می‌کند و سپس APK را می‌سازد. مدل ۶۴ مگابایتی و runtime حدود ۲۹ مگابایتی در مخزن نگهداری نمی‌شوند و هنگام راه‌اندازی در cache گوشی دانلود می‌شوند.

## صدای فارسی و مجوز

صدای پیش‌فرض یک گویندهٔ فارسی ایران، کیفیت medium و نرخ ۲۲٫۰۵ کیلوهرتز است. موتور Python Piper در سرویس آنلاین و کتابخانهٔ Piper WebAssembly در برنامهٔ محلی استفاده می‌شوند. Piper قابلیت‌های clone voice یا کنترل احساسی شبیه سرویس‌های تجاری ندارد. پیش از بازتوزیع، اعلان‌ها و مجوزها در [`THIRD_PARTY_NOTICES.md`](THIRD_PARTY_NOTICES.md) را ببینید.

## نکتهٔ سازگاری

برای حالت محلی، WebView گوشی باید از WebAssembly SIMD و فضای ذخیره‌سازی OPFS پشتیبانی کند؛ در صورت خطای آماده‌سازی، Android System WebView یا Chrome را به‌روز کنید. نخستین بار برای دریافت فایل‌های runtime و مدل اتصال اینترنت لازم است.
